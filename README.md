# FYP: Code Plagiarism Detection and Generative AI

## Abstract
Code plagiarism is an issue in computer science education, and as a result various techniques have been proposed to handle this issue. The introduction of AI-generated code has brought new challenges with code plagiarism detection. This project/report explores the issue of code plagiarism in the context of AI and human-written code and focuses on the development and evaluation of existing plagiarism detection algorithms. A plagiarism detection algorithm was implemented and researched, using a token-based analysis technique, other plagiarism detection techniques were researched and used as a comparison such as abstract syntax tree comparison algorithm and control flow/ program dependency comparison algorithm. A comprehensive data set was used to test the effectiveness of the algorithm. The results were evaluated using precision and recall. The findings highlight the strengths and limitations of each technique, they also offering insights into the applicability in academic settings.
